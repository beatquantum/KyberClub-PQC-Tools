# Kyber Club Privacy Policy Summary

Kyber Club is committed to protecting user privacy and security in our quantum-safe cryptography tools. Below is a summary of key practices:

- **No Key Storage**: Cryptographic keys (e.g., ML-KEM, ML-DSA, SPHINCS+) are generated in memory and never stored, ensuring your data remains secure.
- **CSRF Tokens**: We use Cross-Site Request Forgery (CSRF) tokens to safeguard forms, preventing unauthorised actions.
- **Nonces**: Cryptographic nonces in headers protect scripts and API calls, enhancing platform integrity.
- **GDPR Compliance**: As a London-based platform, we adhere to GDPR for transparent data handling.

For the complete policy, visit [Kyber Club’s Privacy Page](https://kyber.club/privacy).
